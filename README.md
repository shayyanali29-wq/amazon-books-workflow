# Amazon Books Workflow

A step-by-step skill for researching book opportunities, planning and writing a manuscript, editing it, preparing files, and building an evidence-based Amazon launch plan.

It keeps the author in control of the book’s creative choices and publishing account. Market findings are recorded with their date and limits; no sales outcome is promised.

## Use it

Invoke `$amazon-books-workflow` in Codex for a new book or an existing manuscript. It asks book-development questions one at a time, then works through the agreed plan in stages.

To install locally, copy this folder into your Codex skills directory as `amazon-books-workflow`.
